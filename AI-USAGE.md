# AI Usage

## AI Tools Used
- **GitHub Copilot**: Code completion and generation
- **ChatGPT**: Documentation, code generation and improvement, and research
- **Gemini**: Documentation, code generation and improvement, and research

### Code Development
- Generated code for core logical functions like calculating mean values, or dropping the selected columns from dataframe
- Hugely assisted with debugging and optimization suggestions
- Helped to write meaningful comments and clean code structure
- Helped to improve manually created code using Streamlit to adjust to the general structure of the app

### Documentation
- Assisted in writing README and inline comments

## Limitations Acknowledged
- All AI generated code was reviewed and tested
- Manual verification of logic and correctness performed
- Business logic and app structure designed independently
- Most of the cases streamlit documentations were more convinient to use than AI

## Generated vs. Original
- ~40% of helper functions generated with AI assistance
- Core structure and data pipeline: manually developed
- All codes adapted to project-specific requirements
- All the suggested codes of AI were verified manually line by line
